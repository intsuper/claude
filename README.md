# Altitude — Creative Operating System

A stage-gated weekly workflow for a creative strategist driving Facebook creative
toward the one goal that matters: **$5,000/day of profitable spend** (spend running
at 2.0+ ROAS), held consistently.

It brings the **80/20 rule into the creative world** — broad view first, nuance
never. Open `index.html` in any browser. All data lives in your browser
(`localStorage`); nothing is sent anywhere.

## The weekly flow (you can't skip a stage)

1. **The Big Picture** — the $5K/day profitable-spend gauge, then winners-vs-losers
   volume per product, then the 3 highest-impact moves right now.
2. **Pick the Battle** — choose one product and one play for the week.
3. **Call Every Creative** — scale / cut / iterate / keep, line by line.
4. **Build the Action List** — your calls turned into concrete tasks.
5. **Commit the Week** — lock the plan and the projected impact, then run it again.

Each stage unlocks only once the previous one is done.

## Stage 1, exactly as specified

- **Top — the goal.** Current profitable daily spend vs. the $5K/day target, with a
  Today / 7-day / 30-day toggle, the gap to goal, unprofitable spend bleeding per
  day, and spend efficiency.
- **Middle — the volume card.** For each product, a green *winners* pillar (≥ 2.0
  ROAS) beside a red *losers* pillar (< 2.0), on one shared scale, with spend and a
  profitable-% bar.
- **Bottom — the recommendation.** A real engine scores **Cut losers / Scale
  winners / Get more winners / Iterate** for every product against the $5K goal and
  surfaces the top 3.

## Your data

The tool ships with clearly-labelled **sample** products so it works on first open.
Use **Manage products & data** to swap in your real Facebook numbers (spend + ROAS
per creative, per timeframe). Edits persist locally.

Built with plain HTML/CSS/JS — no build step, no dependencies.
